Total students:
db.studentsAgg.aggregate([
    {
        $count: "totalStudents"
    }
])

Average CGPA:
db.studentsAgg.aggregate([
    {
        $group: {
            _id: null,
            averageCGPA: { $avg: "$cgpa" }
        }
    }
])

Highest CGPA:
db.studentsAgg.aggregate([
    {
        $group: {
            _id: null,
            highestCGPA: { $max: "$cgpa" }
        }
    }
])

Work with courses array:
db.studentsAgg.aggregate([
    {
        $unwind: "$courses"
    }
])
